Responsive Design Principles

The three foundational pillars of modern responsive web design

⇄

Fluid Layouts

Use percentage-based widths and CSS Grid / Flexbox so elements resize proportionally rather than overflowing their containers.

CSS Example

.container {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(200px, 1fr));
  gap: 1.5rem;
}
📷

Flexible Media

Images, videos, and other embedded media should scale within their parent containers, never overflowing or distorting.

CSS Example

img, video, iframe {
  max-width: 100%;
  height: auto;
  display: block;
}
📱

Breakpoints

Media queries define specific viewport widths at which the layout reorganises to best suit the available screen space.

CSS Example

/* Tablet */
@media (max-width: 900px) {
  .grid { grid-template-columns: 1fr 1fr; }
}
/* Mobile */
@media (max-width: 600px) {
  .grid { grid-template-columns: 1fr; }
}
