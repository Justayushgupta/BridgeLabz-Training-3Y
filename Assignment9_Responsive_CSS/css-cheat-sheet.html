CSS Cheat Sheet

Quick reference for Filters, Media Queries, Responsive Design & Typography

CSS Filters

Apply graphical effects like blur, grayscale, sepia, brightness, contrast, and hue-rotate directly to HTML elements. 

/* Apply and remove on hover */
img { filter: grayscale(100%);
      transition: filter 0.4s ease; }
img:hover { filter: none; }

Media Queries

Conditionally apply CSS rules based on viewport width, height, orientation, or other device characteristics. 

/* Mobile-first breakpoints */
@media (max-width: 600px) {
  .container { flex-direction: column; }
}
@media (min-width: 900px) {
  .grid { grid-template-columns: 1fr 1fr 1fr; }
}

Responsive Design

Fluid grids, flexible images, and media queries form the three pillars of responsive web design (RWD). 

/* Fluid grid column */
.column {
  width: 100%;
  max-width: 1200px;
  margin: 0 auto;
}
img { max-width: 100%; height: auto; }

Responsive Typography

Use clamp() and viewport units to scale font sizes fluidly without defining many breakpoints. 

h1 {
  font-size: clamp(1.5rem, 4vw, 3rem);
}
p {
  font-size: clamp(1rem, 2vw, 1.5rem);
  line-height: 1.6;
}

Flexbox

One-dimensional layout model that distributes space along a single axis (row or column) and aligns items with ease. 

.container {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
  justify-content: space-between;
  align-items: center;
}

CSS Grid

Two-dimensional layout system that controls both rows and columns, ideal for complex page structures. 

.grid {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(200px, 1fr));
  gap: 1.5rem;
}
