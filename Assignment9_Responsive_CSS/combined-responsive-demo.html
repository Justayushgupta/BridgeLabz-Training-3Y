What is Responsive Design?

Responsive web design (RWD) is an approach that ensures web pages render well on a variety of devices and window or screen sizes. Content, design, and performance are all necessary across all devices to ensure usability and satisfaction.

RWD uses three core techniques:

  • Fluid grids – proportional column widths using percentages
  • Flexible images – images that scale within containers
  • Media queries – CSS rules that activate at breakpoints

Together these techniques ensure a single codebase serves an optimal experience from a 320 px phone screen up to a 4K desktop display.

CSS Quick Reference

clamp()

font-size: clamp(1rem, 2vw, 1.5rem);

Grid auto-fit

grid-template-columns:
  repeat(auto-fit, minmax(200px, 1fr));

CSS Filter

filter: grayscale(100%);
transition: filter 0.4s ease;

Media Query

@media (max-width: 700px) {
  .grid { grid-template-columns: 1fr; }
}
